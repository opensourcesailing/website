# ADR-0001

## Title

Open Source Sailing is an Ecosystem, not a Website.

## Status

Accepted

## Context

The project started as a website but quickly evolved into a broader vision including software, hardware, documentation, education and community.

## Decision

Treat Open Source Sailing as an ecosystem composed of multiple independent projects.

## Consequences

- Website is one repository.
- CLI is another repository.
- Documentation is shared.
- Branding is shared.
- Configuration is shared.
